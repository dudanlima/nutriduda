Cadastre uma paciente primeiro, no painel, para montar o plano.

Gerar cardápio a partir de um modelo

Escolha um modelo de um dia já importado. A IA usará a estrutura dele como referência para criar os dias solicitados.

Ao gerar, o modelo escolhido e dados clínicos necessários ao plano, como sexo, idade, peso, altura, objetivo, restrições e preferências, serão enviados à API do Gemini usando a chave salva neste navegador. O nome da paciente não é incluído automaticamente. O cardápio e os valores nutricionais gerados são estimativas para revisão profissional.
